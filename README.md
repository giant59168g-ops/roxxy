# 🎮 Streamer Bio Page

เว็บไซต์หน้า Bio ส่วนตัวสำหรับแนะนำตัวและรวบรวมช่องทางการติดตามต่างๆ ของสตรีมเมอร์ สร้างขึ้นเพื่อความสะดวกในการแชร์ลิงก์โซเชียลมีเดีย แพลตฟอร์มสตรีมมิ่ง และผลงานต่างๆ ไว้ในที่เดียวจบ!

## ✨ ฟีเจอร์หลัก (Features)
* 🔗 **Hub for Everything:** รวบรวมทุกลิงก์ช่องทางการติดตาม (Twitch, YouTube, Facebook, TikTok ฯลฯ) ไว้ในหน้าเดียว
* 🎵 **Background Music:** มีลูกเล่นเสียงเพลงประกอบเพื่อเพิ่มบรรยากาศและบ่งบอกสไตล์ของช่อง (ผ่านไฟล์ `music.mp3`)
* 🎨 **Custom Design:** ตกแต่ง UI ให้สวยงาม อ่านง่าย และเข้ากับเอกลักษณ์ของสตรีมเมอร์
* 🚀 **Fast & Lightweight:** เว็บไซต์โหลดไว เขียนด้วย Pure HTML/CSS

## 🛠️ เครื่องมือและเทคโนโลยีที่ใช้ (Tech Stack)
* **HTML5:** โครงสร้างหลักของหน้าเว็บไซต์
* **CSS3:** ตกแต่งสไตล์ จัดวางเลย์เอาต์ และแอนิเมชัน
* **Visual Studio Code:** โปรแกรมที่ใช้ในการเขียนและแก้ไขโค้ด
